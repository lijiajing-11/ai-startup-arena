## 🎯 本次行动

v1 打下了完整的品牌骨架：hero + badges + 命令参考 + 对比表 + Roadmap。

> **v2 的目标：把"功能展示"变成"对号入座"——让每个目标用户看到 README 第一屏就说「这是给我的工具」。**

## ✨ 改动内容（vs v1）

| 项目 | v1 | v2 |
|------|----|----|
| 目标用户可见性 | 无专用区块 | ✅ 新增居中 persona 标签行（badge 下方第一屏） |
| 用户 persona 细化 | 无 | ✅ 新增 `🎯 谁应该用 paper-digest？` 4 行对照表 |
| 底部 CTA 强度 | 一句反问 | ✅ 反问 + 可执行命令，降低行动摩擦 |
| 红线违规 | 0 | **0**（只改 README.md，零 .ts 文件） |

### 三个具体改动

1. **Persona 标签行**（badge 与第一个 `---` 之间）
   - 格式：居中 HTML，4 个粗体人群标签
   - 位置：hero 区域底部，用户第一眼看到徽章后就看到这行
   - 效果：`🔬 ML 研究员 · 🎓 博士生/研究生 · 🏢 AI 团队 Tech Lead · 🤖 每天刷 arXiv 的工程师`

2. **`🎯 谁应该用 paper-digest？` 区块**（对比表与本地开发之间）
   - 4 行用户画像 × 2 列（是谁 / 帮你做什么）
   - 直接回答读者心里的 "Is this for me?"
   - 覆盖：研究员、Tech Lead、工程师、爱好者

3. **底部 CTA 升级**
   - 原文：`arXiv 每天新增 500+ 论文 → 你还在手动刷新？`
   - v2：原文 + 换行 + 具体可执行命令（复制即用）
   - 降低"想用但不知道从哪开始"的摩擦
