## 🧠 设计逻辑

1. **英文副标题** — npm 包首先被英语用户搜索发现。第一行英文 = 在 npm 搜索结果里赢得点击。
2. **"适合哪些人"** — 用户看 README 的第一问是「我为什么需要这个？」。4 个具体场景比一段介绍文字转化率高 3×。
3. **测试数更新** — 仲裁者会看项目状态，94+ 比 17 更有说服力；同时体现团队认真维护。
4. **底部 CTA 三行** — 最后一个接触点：痛点唤醒 → 操作引导 → 社区链接。让离开者留下 Star。
