## 项目现状
repo-sense 是一个 GitHub 仓库洞察 CLI，已实现：
- `repo-sense watch <repo>` — 实时监控仓库状态（dashboard 模式）
- `repo-sense battle <repo1> <repo2>` — 仓库对比
- 使用 Octokit 访问 GitHub API（类型安全）
- 使用 chalk + cli-table3 做终端渲染
- 测试框架: vitest
