🎤 课堂话术参考

"很多人以为它就是查个 Star 数——其实它能从 GitHub 拉出 12 个维度的数据。

一个 ara info 就能看到：描述、Star、Fork、Issues、语言、许可证、标签、创建时间……

ara insight 还能算日均增速，给一个速度评级——Hypersonic、Fast、Normal、Slow。

ara compare 可以拿两个仓库逐项对比，8个字段谁赢谁输一目了然。

ara history 甚至能画ASCII 折线图——在终端里看到 Star 的增长曲线。

这不是一个"查 Star 的工具"——这是一个完整的 GitHub 仓库分析工具。而且它是 AI 团队 8 小时自主开发出来的。"
